# 유물 비트 설계서

4Bit_Prototype 유물 비트 메이커(`relic-beat-tool/`)에서 내보낸 파일이다. 유물마다 악기 하나로 찍은 16박 루프다.

> **장르 설계: 아케이드 신스펑크 v1 — 17개 파트가 맞물리는 2마디 루프.** 100BPM 4/4, 1칸 = 16분음표, 32칸 = 2마디. 각 파트는 단선율 리프나 짧은 스탭 하나만 맡고, 칸과 음역을 나눠 서로의 빈 곳을 채운다. 어떤 5개를 골라도 같은 곡의 부분집합으로 들리게, 17개 전부를 겹친 최대 밀도 상태를 먼저 맞춘 뒤 나눴다.
>
> **화성:** C 도리안, 마디 1 = Cm7(칸 0~15), 마디 2 = F7(칸 16~31). 코드 경계를 넘어 울리는 음은 공통음(C·E♭)만 쓰고, 앞당김(칸 15·31)은 다음 코드의 음을 쓴다. F7 마디에는 B♭을 쓰지 않는다.
>
> **역할 (등급별):** 유물 이름과 악기는 맞추지 않았다. 자주 나오는 일반 등급에 기초를, 희귀에 색깔을, 에픽에 특별한 층을 두었다.
> - 일반: 서브우퍼 = 선 베이스(일렉 베이스, 근음 + 16분 당김음), 킥 솔로 = 점 베이스(신스 베이스, 8분 뒷박 옥타브), 리허설 = 로즈 컴핑, 레퍼토리 = 치킨 스크래치 기타(고스트 위주), 크래시 심벌 = 8분 하이햇, 스네어 솔로 = 카우벨 손 클라베 3-2, 에어 드럼 = 콩가 툼바오
> - 희귀: 프리스타일 = 리드 기타 훅(마디 1), 카운터포인트 = 글로켄슈필 응답(마디 2, 딜레이), 스포르찬도 = 브라스 앞당김 악센트, 메트로놈 = 2마디에 걸쳐 커지는 16분 셰이커, 워킹 베이스 = 오픈 하이햇(a 칸), 탭 댄스 = 하이 톰 필(루프 끝), 턴테이블 = 스크래치
> - 에픽: 퀀타이즈 = 사각파 16분 아르페지오(3칸마다 강세, 로파이), 페르마타 = 지속 패드(배경), 크레센도 = 808 서브(칸 0·16 무게)
>
> **맞물림 규칙:** 베이스 3개는 시작 칸이 서로 겹치지 않는다(선 베이스는 정박·a, 점 베이스는 &, 808은 칸 0·16에서 선 베이스와 같은 음). 리드(마디 1)와 글로켄슈필(마디 2)은 마디를 번갈아 쓴다. 로즈와 브라스는 칸이 겹치지 않는다. 고스트 노트는 세기 0.25~0.4다. 사이드체인은 쓰지 않는다(게임에서 무기 킥이 박자 격자에 고정되지 않는다).
>
> **검증:** 17개를 모두 겹쳐 릴리스 꼬리와 딜레이 메아리(3·6칸 뒤)까지 넣어 계산했을 때 반음 충돌 0건. 5개 조합 6188가지 중 베이스 없음 32.4%, 베이스 2개 이상 19.1%(서로 맞물림), 중음 악기 3개 이상 5.3%, 조합당 아무 파트도 시작하지 않는 칸 평균 4칸. 렌더 피크는 단독 0.92 이하, 5개 믹스(무작위 12조합) 0.93 이하, 17개 전부 0.94.
>
> **권장 툴 설정:** 데모 드럼 = 록/J-pop(무기 백비트 소드와 같은 백비트), 드럼 볼륨 60%, 스윙 10%(파일에 들어 있음), 바이닐 노이즈 끔. 역할 설계 문서: `synthfunk-roles.md`.

## 읽는 법

- **시간 기준:** 1박 = 0.3초(게임 링 박자와 같음), 16박 = 32칸, 칸 하나 = 0.5박 = 0.15초, 루프 = 4.8초. 루프는 이음매 없이 반복한다.
- **칸 번호:** 0~31. 칸 i는 루프 시작 후 i x 0.15초에 울린다. "박.위치" 표기로 칸 0 = 1.0, 칸 1 = 1.5, 칸 2 = 2.0 … 칸 31 = 16.5다.
- **음 표기:** 과학적 음이름(C4 = MIDI 60, 샵 표기). 쉬는 칸은 `-`, 음높이 없는 타악은 `X`, 같은 칸의 여러 음(화음)은 `+`로 잇는다.
- **세기:** 음 뒤 `@m`은 중(0.7), `@w`는 약(0.4)이고 표기가 없으면 강(1.0)이다 (타악은 `X@m`). JSON `velocity`는 노트 게인 배율이고 없으면 1이다.
- **노트 길이:** 기본 1칸이다. `C3*4`처럼 `*칸 수`가 붙은 음높이 노트는 그만큼 이어지고 표에서 이어지는 칸은 `=`다(JSON `length`, 없으면 1, 타악은 쓰지 않음). 게이트 = max(길이 x 0.15초, 어택+디케이, 홀드)이고 루프 끝을 넘는 길이는 루프 끝에서 자른다. 악기의 릴리스는 게이트 뒤로 이어진다.
- **롤:** `X/3`처럼 `/N`이 붙은 노트는 그 칸에서 N번 나눠 친다 (JSON `repeat` 2~4, 없으면 1). 칸(스윙 반영)을 N등분한 간격으로 같은 세기로 치고, 한 번의 게이트는 그 간격이다. 롤 노트는 길이를 쓰지 않는다(1칸). 표기 순서는 음, 길이, 롤, 세기다 (예: `C3/2@m`).
- **스윙:** 10% (JSON `groove.swing`). 칸 i의 시각 = i x 0.15초 + (i가 홀수면 swing x 0.15초). 노트의 끝 경계도 같은 규칙을 따른다.
- **믹스 설정 (유물별, 없으면 0):** `sidechain`은 킥마다 유물 소리를 (1 - 값)까지 0.01초에 눌렀다가 0.2초에 되돌린다. 툴에서는 데모 드럼 킥에 맞추고, 게임에서는 무기 킥 시각에 맞춰 눌러야 한다. `reverbSend`·`delaySend`는 공통 리버브(감쇠 노이즈 임펄스 1.6초)와 공통 딜레이(0.45초 = 1.5박, 피드백 0.35, 피드백 로우패스 3000Hz)로 보내는 양이다. `lofi`는 계단 곡선(12비트에서 3비트로)과 로우패스(18000Hz에서 2500Hz로)를 값에 따라 건다. `lowCut`(저음 깎기)은 하이패스 20 x (800 / 20)^값 Hz, `highCut`(고음 깎기)은 로우패스 20000 x (800 / 20000)^값 Hz다 (값 1이면 둘 다 800Hz, Q 0.707, 12dB/oct). 소리 경로는 볼륨, 사이드체인, 하이패스, 로우패스, 로파이 순이고 센드는 그 뒤에서 뽑는다.
- **데모 드럼:** 툴의 데모 드럼(킥·스네어)은 미리듣기 전용이며 이 데이터에 없다.
- **스케일:** C 도리안 (루트 C, 반음 간격 0 2 3 5 7 9 10). 음높이 악기는 스케일 음 8개(행 0이 가장 낮다), 타악은 행 1개다.
- **원본 데이터:** 맨 아래 JSON이 원본이고 위의 표는 JSON에서 만든 것이다. 둘이 다르면 JSON을 따른다. 툴의 불러오기도 JSON만 읽는다.
- **게임 반영 시 주의:** 게임의 쿵(A)·짝(S) 판정 소리와 겹치지 않게 킥·스네어 음색은 쓰지 않았다. 박 시작은 게임 링 박자에 맞추고, 볼륨(`volume` x `mixVolume`)은 상대값이다. 합성 파라미터는 Web Audio API 기준(오실레이터 파형, BiquadFilter, 게인 엔벨로프)이다.
- **선택 파라미터:** `distortion`(WaveShaper tanh 곡선, drive가 클수록 강함, 필터 앞), `fm`(사인 모듈레이터가 주파수를 변조, 깊이 = index x 모듈레이터 Hz가 decay초 동안 0으로), `vibrato`(LFO로 detune을 ±depth센트 흔듦, delay초 뒤 시작), `hold`(게이트를 max(0.15초, 어택+디케이, hold)로 늘림), `filterLfo`(사인 LFO가 메인 필터 주파수에 ±depth Hz를 rate Hz로 더함, 노트 시작에 위상 0)는 있는 프리셋에만 쓴다. 없으면 그 처리를 하지 않는다.
