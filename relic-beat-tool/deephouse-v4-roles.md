# 딥하우스 v4 — 역할표

`relic-beats-deephouse-v4.md`의 설계 근거 문서다. 노트 데이터의 원본은 그 설계서의 JSON이다. v1~v3는 템포 고정(100BPM) 시절의 옛 딥하우스 설계서라 번호를 이어 v4로 했다.
(파일 이름이 `relic-beats-*`가 아니어서 툴 불러오기와 기준 렌더 대상에 들어가지 않는다.)

## 1. 방향

- 하우스 v1의 뼈대(킥 칸을 비우는 베이스·건반, 오프비트 하이햇, 타악만 스윙)를 그대로 두고, `request-deephouse-depth.md`로 생긴 기능으로 깊이를 더한다.
  - 공간: 코러스, 홀 리버브
  - 질감: 트레몰로 로즈, 보컬 모음, 테이프
  - 긴 흐름: 16마디 사이클, 필터 스윕 `upDown`, 등장 루프
- 화성 리듬을 2마디로 늦추고 9화음 보이싱을 쓴다.

## 2. 설정과 화성

- 120BPM, 16분 격자(64칸 = 4마디), F 단조(C 자연 단음계 + root 5), 15행, 사이클 4루프(16마디), 딜레이 점8분(3칸), 전체 스윙 0.
- 15행: F3 G3 A♭3 B♭3 C4 D♭4 E♭4 F4 G4 A♭4 B♭4 C5 D♭5 E♭5 F5 (옥타브 3 악기 기준).
- Fm9(칸 0~31) → B♭m9(칸 32~63).
- 로즈 보이싱:
  - Fm9 = A♭3-E♭4-G4-C5
  - B♭m9 = A♭3-D♭4-F4-C5
  - A♭과 C를 붙잡고 E♭→D♭, G→F만 온음으로 움직인다.
- 패드(A♭3-F4-C5)와 스트링(F4-C5)은 두 코드의 공통음만 써서 루프 내내 이어진다.
- 충돌 기준: 단2도 계열(1·13·25반음)만 막는다. 장7도(11반음, 예: G4와 A♭3)는 9화음의 색이라 허용한다.

## 4. 검증 결과

| 항목 | 값 |
|---|---|
| 단2도 계열 충돌 (17개 전부 + 릴리스 꼬리 + 딜레이 메아리) | 0건, 약한 겹침 0건 |
| 코드 구성음 비율 | 98.5% |
| 게임식 추첨 2만 회: 베이스 없음 / 중음 3개 이상 | 31.2% / 5.3% |
| 렌더 피크 (유물 볼륨 반영): 단독 / 무작위 5개 사이클 믹스 6개 / 딥 킥 포함 | 0.80 이하 / 0.92 이하 / 0.92 (볼륨 최종 조정 전 값, 조정은 낮추는 쪽뿐) |
| 이음매 | 사이클 WAV와 루프 WAV 모두 끝→처음 변화가 평소 샘플 간 최대 변화보다 작다 |
| 불러오기 | 17개 유물·노트 309개·모든 설정이 같다 (`filterSweep.shape` 기본값 `up`은 내보낼 때 생략되어 같은 뜻) |

- 처음 계산에서 3건이 걸려 고쳤다.
  - 마지막 마디 베이스 C 픽업과 D♭4가 단9도로 겹쳤다.
  - 벨 A♭5 메아리와 G4가 단9도로 겹쳤다.
  - 훅 G4 메아리와 오르간 A♭4가 반음으로 겹쳤다.
- 이 3건을 고치면서 바꾼 것: 베이스 픽업을 F로, 벨 음을 B♭·F로, 훅 G4 길이를 2칸으로, 오르간 B♭m 보이싱을 D♭-F-B♭으로.
- 베이스가 하나뿐이라 베이스 없는 조합이 57%였다. 808 서브를 일반 등급에 더해 31%로 줄였다.

## 5. 툴 확인 (이번 구현)

- 코러스 1을 걸면 좌우 상관계수가 0.44로 떨어진다(없으면 0.985). 100·124·180BPM 모두 같다.
- 코러스·홀·테이프·트레몰로를 각각 건 WAV는 100·124·180BPM에서 이음매가 없다.
- 사이클 렌더 길이가 루프 x 4와 정확히 같다.
- 등장 루프 `[false, true, true, true]`인 유물은 첫 루프 구간 RMS가 0이다.
- 콘솔 오류는 없다.

## 6. 들어 볼 때

- 툴 설정:
  - 데모 드럼: 하우스/EDM, 킥 음색 딥, 드럼 볼륨 60~70%
  - 펌핑 기준: 4분 정박
  - 바이닐 노이즈: 켜기(취향)
  - 사이클 흐름을 들으려면 믹스 재생을 16마디(약 32초) 이상 듣거나 WAV 길이를 '한 사이클'로 내보낸다.
- 뼈대: 서브우퍼 + 리허설 + 레퍼토리 + 크래시 심벌 + 킥 솔로.
- 16마디 흐름: 크래시 심벌(패드 스윕) + 크레센도(스트링 3·4루프) + 퀀타이즈 + 페르마타 + 레퍼토리.
- 질감 비교: 리허설(로즈 트레몰로)을 단독으로 코러스·테이프를 0으로 내렸다가 다시 올려 들어 본다.
