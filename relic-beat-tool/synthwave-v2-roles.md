# 신스웨이브 v2 — 역할표

`relic-beats-synthwave-v2.md`의 설계 근거 문서다. 노트 데이터의 원본은 그 설계서의 JSON이다.
(파일 이름이 `relic-beats-*`가 아니어서 툴 불러오기와 기준 렌더 대상에 들어가지 않는다.)

## 1. 방향

- 사용자가 들어 보고 괜찮다고 한 v1의 소리를 유지하고, 조합했을 때 탁해지는 원인만 고친다.
- 루프 음악에서는 반복 자체가 추진력이다(`mc-style-edm` §5.2). 그래서 같은 진행 반복이나 아르페지오는 그대로 둔다. 손대는 것은 화음 꼬리, 중음 몰림, 같은 일을 하는 파트, 무기 드럼과 겹치는 파트다.

## 2. 화성과 시간

- C 자연 단음계(행 0~7 = C D E♭ F G A♭ B♭ C), 스윙 0%.
- Cm(칸 0~7) → A♭(8~15) → E♭(16~23) → B♭(24~31). 1칸 = 16분음표, 8칸 = 반 마디.
- 이웃 코드 사이 공통음: Cm–A♭ = C·E♭, A♭–E♭ = E♭, E♭–B♭ = B♭, B♭–Cm = 없음. 경계를 넘어 울리는 음(긴 음, 딜레이 메아리)은 이 공통음을 쓴다.
