# 유물 비트 설계서

4Bit_Prototype 유물 비트 메이커(`relic-beat-tool/`)에서 내보낸 파일이다. 유물마다 악기 하나로 찍은 16박 루프다.

> **장르 설계: 붐뱁(boom bap) 힙합 — 유물 이름과 무관한 17개 파트.** 어떤 5개를 골라 섞어도 먼지 낀 샘플 느낌의 붐뱁으로 들리도록, 이름 대신 소리 역할을 기준으로 짰다. 파트를 1~17번 유물에 순서대로 붙였고 이름과 악기는 일부러 연결하지 않았다.
> **붐뱁이 이 툴에 잘 맞는 이유:** 툴의 100BPM이 붐뱁의 흔한 템포 대역(85~100BPM) 안이고, 2마디 루프에 코드 한두 개를 반복하는 구조가 샘플 루프 기반 장르와 같다. 스윙, 로파이, 바이닐 노이즈, 붐뱁 데모 드럼을 그대로 쓴다.
> **권장 툴 설정**: 데모 드럼 = **붐뱁**(킥 칸 0, 6, 11, 16, 22, 27 / 스네어 칸 4, 12, 20, 28), 스윙 **25%**(홀수 칸이 늦게 울려 처진 느낌이 난다), 바이닐 노이즈는 취향(켜면 먼지 낀 느낌이 강해진다). 설계서에 저장되는 것은 유물별 로파이·리버브·딜레이·사이드체인 값뿐이다.
> **코드 진행**(스케일 C 도리안: 행 0 C, 1 D, 2 Eb, 3 F, 4 G, 5 A, 6 Bb, 7 위 옥타브 C): **Cm7(칸 0~15) → F7(칸 16~23) → Gm7(칸 24~31)**. 소울·재즈 샘플에서 흔한 단7화음 중심 진행이고, 마지막 Gm7이 처음 Cm7로 돌아오는 당김을 만든다. 17개 모두 이 코드의 구성음만 쓴다.
> **섞이는 원리**
> - **역할 분담:** 베이스 3개(일렉 베이스, 808 서브, 워킹 베이스), 코드 4개(일렉 피아노, 어쿠스틱 피아노, 오르간, 클린 기타), 멜로디·악센트 3개(플루트 훅, 마림바, 브라스 스탭), 드럼 6개(킥, 클랩, 닫힌·열린 하이햇, 셰이커, 라이드), 스크래치 1개다.
> - **리듬이 비켜 간다:** 킥·클랩은 데모 드럼 위치에 겹치고, 닫힌 하이햇은 8분, 셰이커는 스윙 16분, 라이드는 재즈 스윙 패턴, 피아노는 뒤 16분의 두 음 응답, 브라스 스탭은 코드 끝 뒤 16분, 로즈 피아노는 박 머리 길게 + 뒤 16분 짧게로 맡는다.
> - **로파이:** 건반·기타·플루트·브라스·마림바에는 로파이 20~35%를 걸어 샘플 질감을 냈다. 드럼과 서브는 선명하게 둔다.
> - **사이드체인:** 오르간 25%, 808 서브 40%로 약하게만 걸었다(붐뱁은 강한 펌핑이 어울리지 않는다).

## 읽는 법

- **시간 기준:** 1박 = 0.3초(게임 링 박자와 같음), 16박 = 32칸, 칸 하나 = 0.5박 = 0.15초, 루프 = 4.8초. 루프는 이음매 없이 반복한다.
- **칸 번호:** 0~31. 칸 i는 루프 시작 후 i x 0.15초에 울린다. "박.위치" 표기로 칸 0 = 1.0, 칸 1 = 1.5, 칸 2 = 2.0 … 칸 31 = 16.5다.
- **음 표기:** 과학적 음이름(C4 = MIDI 60, 샵 표기). 쉬는 칸은 `-`, 음높이 없는 타악은 `X`, 같은 칸의 여러 음(화음)은 `+`로 잇는다.
- **세기:** 음 뒤 `@m`은 중(0.7), `@w`는 약(0.4)이고 표기가 없으면 강(1.0)이다 (타악은 `X@m`). JSON `velocity`는 노트 게인 배율이고 없으면 1이다.
- **노트 길이:** 기본 1칸이다. `C3*4`처럼 `*칸 수`가 붙은 음높이 노트는 그만큼 이어지고 표에서 이어지는 칸은 `=`다(JSON `length`, 없으면 1, 타악은 쓰지 않음). 게이트 = max(길이 x 0.15초, 어택+디케이, 홀드)이고 루프 끝을 넘는 길이는 루프 끝에서 자른다. 악기의 릴리스는 게이트 뒤로 이어진다.
- **롤:** `X/3`처럼 `/N`이 붙은 노트는 그 칸에서 N번 나눠 친다 (JSON `repeat` 2~4, 없으면 1). 칸(스윙 반영)을 N등분한 간격으로 같은 세기로 치고, 한 번의 게이트는 그 간격이다. 롤 노트는 길이를 쓰지 않는다(1칸). 표기 순서는 음, 길이, 롤, 세기다 (예: `C3/2@m`).
- **스윙:** 없음. JSON에 `groove.swing`이 있으면 칸 i의 시각 = i x 0.15초 + (i가 홀수면 swing x 0.15초)다.
- **믹스 설정 (유물별, 없으면 0):** `sidechain`은 킥마다 유물 소리를 (1 - 값)까지 0.01초에 눌렀다가 0.2초에 되돌린다. 툴에서는 데모 드럼 킥에 맞추고, 게임에서는 무기 킥 시각에 맞춰 눌러야 한다. `reverbSend`·`delaySend`는 공통 리버브(감쇠 노이즈 임펄스 1.6초)와 공통 딜레이(0.45초 = 1.5박, 피드백 0.35, 피드백 로우패스 3000Hz)로 보내는 양이다. `lofi`는 계단 곡선(12비트에서 3비트로)과 로우패스(18000Hz에서 2500Hz로)를 값에 따라 건다.
- **데모 드럼:** 툴의 데모 드럼(킥·스네어)은 미리듣기 전용이며 이 데이터에 없다.
- **스케일:** C 도리안 (루트 C, 반음 간격 0 2 3 5 7 9 10). 음높이 악기는 스케일 음 8개(행 0이 가장 낮다), 타악은 행 1개다.
- **원본 데이터:** 맨 아래 JSON이 원본이고 위의 표는 JSON에서 만든 것이다. 둘이 다르면 JSON을 따른다. 툴의 불러오기도 JSON만 읽는다.
- **게임 반영 시 주의:** 게임의 쿵(A)·짝(S) 판정 소리와 겹치지 않게 킥·스네어 음색은 쓰지 않았다. 박 시작은 게임 링 박자에 맞추고, 볼륨(`volume` x `mixVolume`)은 상대값이다. 합성 파라미터는 Web Audio API 기준(오실레이터 파형, BiquadFilter, 게인 엔벨로프)이다.
- **선택 파라미터:** `distortion`(WaveShaper tanh 곡선, drive가 클수록 강함, 필터 앞), `fm`(사인 모듈레이터가 주파수를 변조, 깊이 = index x 모듈레이터 Hz가 decay초 동안 0으로), `vibrato`(LFO로 detune을 ±depth센트 흔듦, delay초 뒤 시작), `hold`(게이트를 max(0.15초, 어택+디케이, hold)로 늘림), `filterLfo`(사인 LFO가 메인 필터 주파수에 ±depth Hz를 rate Hz로 더함, 노트 시작에 위상 0)는 있는 프리셋에만 쓴다. 없으면 그 처리를 하지 않는다.
