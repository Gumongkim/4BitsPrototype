# 유물 비트 설계서

4Bit_Prototype 유물 비트 메이커(`relic-beat-tool/`)에서 내보낸 파일이다. 유물마다 악기 하나로 찍은 16박 루프다.

> **장르 설계: J-pop 밴드 (신규).** 밝은 장조 위에서 8분음표로 달리는 4인조 밴드 편성이다. 드럼은 게임의 무기가 내므로 킥·스네어 음색은 없고, 톰·클랩·하이햇·심벌과 베이스·기타·건반·현·신스로 층을 나눴다. 17종 모두 같은 코드 진행을 따르므로 어떤 5개를 겹쳐도 한 곡으로 들린다.
> **코드 진행**(16박 = 2마디, 1박 = 8분음표, 1칸 = 16분음표, 100BPM 기준): Am(1~4박) → F(5~8박) → C(9~12박) → G(13~16박). 일본 록·팝에서 많이 쓰는 vi–IV–I–V이고, G에서 Am으로 돌아갈 때 루프가 이어진다. 스케일은 C 장음계(행 0 C, 1 D, 2 E, 3 F, 4 G, 5 A, 6 B, 7 위 옥타브 C)다.
> **권장 툴 설정**: 데모 드럼 = 록/J-pop(파일에 저장되지 않으니 직접 선택), 스윙 0%, 사이드체인은 쓰지 않았다. 킥 위치(데모 드럼 기준 칸 0, 6, 8, 14, 16, 22, 24, 29)에 서브우퍼·스포르찬도가 맞물린다.
> **층 구성**
> - **리듬 (드럼·타악):** 킥 솔로(로우 톰, 4박 끝 쿵), 스네어 솔로(핸드 클랩, 백비트 겹치기), 크래시 심벌(마디 머리), 에어 드럼(미드 톰 필인), 메트로놈(닫힌 하이햇 8분), 턴테이블(스크래치 포인트).
> - **저음:** 서브우퍼(서브 베이스, 킥에 맞춘 근음), 워킹 베이스(일렉 베이스, 8분 근음에 다음 코드로 걸어 들어감).
> - **기타:** 스포르찬도(파워코드 스탭, 킥과 같은 위치), 탭 댄스(팜뮤트 16분 엇박), 카운터포인트(클린 기타 분산화음), 프리스타일(리드 기타 멜로디).
> - **건반·현·신스:** 리허설(어쿠스틱 피아노 코드 컴핑), 레퍼토리(글로켄슈필 상승 분산화음), 크레센도(상승 스트링, 세기가 단계적으로 커짐), 퀀타이즈(아르페지오 신스, 16분 전부 격자에 맞춤), 페르마타(오르간, 속 빈 5도를 길게).
> **자리 배분**: 하이햇·워킹 베이스·클린 기타는 짝수 칸(8분), 글로켄슈필·팜뮤트·스크래치는 홀수 칸(16분 엇박)에 두어 겹쳐도 서로 비켜 간다.

## 읽는 법

- **시간 기준:** 1박 = 0.3초(게임 링 박자와 같음), 16박 = 32칸, 칸 하나 = 0.5박 = 0.15초, 루프 = 4.8초. 루프는 이음매 없이 반복한다.
- **칸 번호:** 0~31. 칸 i는 루프 시작 후 i x 0.15초에 울린다. "박.위치" 표기로 칸 0 = 1.0, 칸 1 = 1.5, 칸 2 = 2.0 … 칸 31 = 16.5다.
- **음 표기:** 과학적 음이름(C4 = MIDI 60, 샵 표기). 쉬는 칸은 `-`, 음높이 없는 타악은 `X`, 같은 칸의 여러 음(화음)은 `+`로 잇는다.
- **세기:** 음 뒤 `@m`은 중(0.7), `@w`는 약(0.4)이고 표기가 없으면 강(1.0)이다 (타악은 `X@m`). JSON `velocity`는 노트 게인 배율이고 없으면 1이다.
- **노트 길이:** 기본 1칸이다. `C3*4`처럼 `*칸 수`가 붙은 음높이 노트는 그만큼 이어지고 표에서 이어지는 칸은 `=`다(JSON `length`, 없으면 1, 타악은 쓰지 않음). 게이트 = max(길이 x 0.15초, 어택+디케이, 홀드)이고 루프 끝을 넘는 길이는 루프 끝에서 자른다. 악기의 릴리스는 게이트 뒤로 이어진다.
- **스윙:** 없음. JSON에 `groove.swing`이 있으면 칸 i의 시각 = i x 0.15초 + (i가 홀수면 swing x 0.15초)다.
- **믹스 설정 (유물별, 없으면 0):** `sidechain`은 킥마다 유물 소리를 (1 - 값)까지 0.01초에 눌렀다가 0.2초에 되돌린다. 툴에서는 데모 드럼 킥에 맞추고, 게임에서는 무기 킥 시각에 맞춰 눌러야 한다. `reverbSend`·`delaySend`는 공통 리버브(감쇠 노이즈 임펄스 1.6초)와 공통 딜레이(0.45초 = 1.5박, 피드백 0.35, 피드백 로우패스 3000Hz)로 보내는 양이다. `lofi`는 계단 곡선(12비트에서 3비트로)과 로우패스(18000Hz에서 2500Hz로)를 값에 따라 건다.
- **데모 드럼:** 툴의 데모 드럼(킥·스네어)은 미리듣기 전용이며 이 데이터에 없다.
- **스케일:** C 장음계 (루트 C, 반음 간격 0 2 4 5 7 9 11). 음높이 악기는 스케일 음 8개(행 0이 가장 낮다), 타악은 행 1개다.
- **원본 데이터:** 맨 아래 JSON이 원본이고 위의 표는 JSON에서 만든 것이다. 둘이 다르면 JSON을 따른다. 툴의 불러오기도 JSON만 읽는다.
- **게임 반영 시 주의:** 게임의 쿵(A)·짝(S) 판정 소리와 겹치지 않게 킥·스네어 음색은 쓰지 않았다. 박 시작은 게임 링 박자에 맞추고, 볼륨(`volume` x `mixVolume`)은 상대값이다. 합성 파라미터는 Web Audio API 기준(오실레이터 파형, BiquadFilter, 게인 엔벨로프)이다.
- **선택 파라미터:** `distortion`(WaveShaper tanh 곡선, drive가 클수록 강함, 필터 앞), `fm`(사인 모듈레이터가 주파수를 변조, 깊이 = index x 모듈레이터 Hz가 decay초 동안 0으로), `vibrato`(LFO로 detune을 ±depth센트 흔듦, delay초 뒤 시작), `hold`(게이트를 max(0.15초, 어택+디케이, hold)로 늘림)는 있는 프리셋에만 쓴다. 없으면 그 처리를 하지 않는다.
