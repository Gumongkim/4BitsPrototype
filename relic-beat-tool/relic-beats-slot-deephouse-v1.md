# 유물 비트 설계서 (슬롯 악기 모드)

> **딥하우스 슬롯 v1.** 슬롯 악기 모드 예시다. 슬롯(로즈 코드 / 딥 베이스 / 셰이커 / 보컬 챱 리드 / 보컬 패드)과 코드 진행(Fm9 Fm9 B♭m9 B♭m9)은 딥하우스 v4에서 가져왔고, 패턴 17개는 리듬 성격(정박·뒷박·당김·긴음·16분·부름/응답)으로 나눠 어떤 5개가 어떤 순서로 모여도 빈 곳을 채우게 했다. 17개 중 5개 6188가지 x 순서 20가지에서 단2도 계열 충돌 0건. 설계 근거와 검증은 `slot-deephouse-v1-roles.md`.
>
> 들어 보기: 데모 드럼 하우스/EDM, 킥 음색 딥, 펌핑 기준 4분 정박. '순서대로 채우기' 후 '쌓기 재생'(사이클마다 한 층씩). 빨리 들으려면 사이클을 1루프로.

4Bit_Prototype 유물 비트 메이커(`relic-beat-tool/`)의 슬롯 악기 모드에서 내보낸 파일이다. 믹스 바 5칸(슬롯)이 악기를 정하고, 유물은 리듬과 코드 기준 높낮이(degree)만 정한다. 유물을 얻은 순서대로 슬롯 1 → 5에 들어가 그 슬롯의 악기로 연주된다.

## 읽는 법

- **시간 기준:** 120BPM(4분음표). 격자 16분: 칸 하나 = 0.125초, 16박 = 4마디 = 64칸, 루프 = 8초. 사이클 4루프 = 16마디.
- **스케일·키:** F 자연 단음계 (C 자연 단음계 + root 5) (반음 간격 0 2 3 5 7 8 10, JSON `root` 5).
- **슬롯:** 아래 슬롯 표의 악기·역할·음역·믹스 설정으로 그 슬롯에 들어간 유물(패턴)을 연주한다. 믹스 설정 항목의 뜻은 유물 악기 모드 설계서와 같다.
- **코드 진행:** 마디마다 `{ root, size }`. root는 스케일 행(0 = 스케일 첫 음), 코드는 그 행부터 스케일 위로 3도씩(행 +2씩) size개(3 = 3화음, 4 = 7화음, 5 = 9화음)를 쌓는다.
- **degree (패턴의 높낮이):** 0 = R(근음), 1 = 3, 2 = 5, 3 = 7, 4 = R'(한 옥타브 위), 5 = 3', 6 = 5', 7 = 9'. 그 칸 마디의 코드 음이다. 3화음이면 7음 자리는 근음 한 옥타브 위, 3·7화음이면 9음 자리는 5음 위로 바꾼다.
- **역할별 변환:** bass = 단음, 슬롯 음역의 가장 낮은 옥타브(degree 4~6은 한 옥타브 위, 7음·9음은 근음으로). chord = degree 음을 맨 위로, 그 아래 한 옥타브 안에 코드 음 voices-1개(앞 화음과 음 이동 합이 가장 작은 자리). lead = 단음, 슬롯 음역 안. pad = chord와 같고 길이를 다음 패턴 노트 직전 또는 코드가 바뀌는 칸 직전까지 늘인다. perc = 음높이를 버리고 타악을 친다. 슬롯 음역 = 프리셋 옥타브 + octaveShift의 C ~ 두 옥타브 위, 벗어나면 옥타브 단위로 안으로 접는다.
- **경계 처리:** 노트가 코드가 바뀌는 칸을 넘으면 거기서 끊는다. 그 음이 다음 코드에도 있으면(공통음) 이어 간다. 화음은 음마다 따로 판단한다.
- **패턴 표기:** 칸마다 degree 기호, 쉬는 칸 `-`, 같은 칸 여러 음은 `+`, `*n` 길이(이어지는 칸 `=`), `/n` 롤, `@m`·`@w` 세기(중 0.7, 약 0.4). 순서: 기호, 길이, 롤, 세기.
- **등장 루프:** 유물의 `loops`(사이클 안 루프별 true/false)가 있으면 false인 루프에서 치지 않는다. 없으면 모든 루프.
- **원본 데이터:** 맨 아래 JSON이 원본이다. 표는 JSON에서 만든 것이다. 이 파일은 `mode: "slot"`이라 슬롯 모드를 모르는 이전 툴로 열면 `notes`·`preset`이 없어 거부된다.
