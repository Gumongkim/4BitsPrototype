# 유물 비트 설계서

4Bit_Prototype 유물 비트 메이커(`relic-beat-tool/`)에서 내보낸 파일이다. 유물마다 악기 하나로 찍은 16박(4마디) 루프다.

> **장르 설계: 딥/보컬 하우스 v1 — 리듬게임용으로 박이 분명한 4마디 루프.** 124BPM, 16분 격자 64칸, A 도리안(C 도리안 + root 9). 킥은 데모 드럼(하우스/EDM, 909 킥)이 매 박에 치고, 유물은 킥 칸(0·4·8·12)을 비워 그 사이를 채운다.
>
> **화성:** Am7(마디 1) → D9(마디 2) → Am7(마디 3) → D9(마디 4). 도리안 i–IV 반복이다. 두 코드의 공통음은 A·C·E이고 부딪히는 음은 G(Am7)와 F#(D9) 하나뿐이다. 마디를 넘어 울리는 음(긴 음, 릴리스, 딜레이 메아리)은 A·C·E만 쓰고, 피아노는 마디 끝 스탭을 공통음 C-E-A로 친다. 보이싱은 Am7 = C-E-G, D9 = C-E-F#-A로 G→F# 반음만 움직인다.
>
> **역할 (등급별, 유물 이름과 무관):**
> - 일반(자주 나옴, 뼈대): 서브우퍼 = 오프비트 딥 베이스(한 옥타브 아래, 킥 칸 비움), 크래시 심벌 = 오르간 베이스 튕김(16분 a 칸), 리허설 = 하우스 피아노 엇박 스탭, 레퍼토리 = 보컬 챱 훅, 에어 드럼 = 플럭 리프(훅 빈자리 응답), 킥 솔로 = 오프비트 오픈 하이햇, 스네어 솔로 = 16분 셰이커(스윙 20%)
> - 희귀(색깔): 카운터포인트 = 로즈 긴 화음, 턴테이블 = 슈퍼소 패드(공통음 E·A만 길게), 메트로놈 = 16분 클로즈드 하이햇(스윙 20%), 스포르찬도 = 핑거 스냅(2·4박), 탭 댄스 = 클라베 3-2, 워킹 베이스 = 콩가 툼바오, 프리스타일 = 마지막 마디 탬버린 크레센도
> - 에픽(빌드업·전환): 크레센도 = 퓨처 코드(정박 큰 화음, 필터 스윕으로 루프 동안 열림), 퀀타이즈 = 노이즈 라이저(루프 머리로 차오름), 페르마타 = 다운리프터(루프 머리에서 내려감)
>
> **리듬게임 관점:** 킥(매 박), 오픈 하이햇(매 8분 뒷박), 클랩·스냅(2·4박)이 박을 계속 알려 준다. 베이스와 피아노는 킥 칸을 비우는 비켜 치기라 킥이 묻히지 않는다. 하이햇·셰이커·클라베·콩가만 유물별 스윙 20%를 걸고, 베이스·화음은 곧게 둬서 박이 흔들리지 않는다.
>
> **훅:** 보컬 챱('아' 모음)이 마디 1에서 E-G-E-D-C로 내려와 근음 쪽에서 멈추고, 마디 2에서 F#-A-F#-E-D로 같은 리듬을 D9 위에서 받는다. 마디 3은 마디 1 반복, 마디 4는 F#-A-E-C-A로 끝을 바꿔 루프 머리 A로 돌아간다. 플럭은 훅이 끄는 칸(8~10, 13, 15)에서만 대답한다.
>
> **검증:** 17개를 모두 겹쳐 릴리스 꼬리와 딜레이 메아리(점8분 = 3칸)까지 계산했을 때 강한 반음 충돌 0건, 약한 겹침 4건(플럭 메아리 0.17칸). 게임식 추첨(카드 3장, 등급 60/30/10, 2만 회)에서 베이스 없음 31.3%, 중음 3개 이상 0.8%. 렌더 피크(유물 볼륨 반영)는 단독 0.727, 무작위 5개 믹스 12개 0.903 이하, 17개 전부 0.9, 데모 드럼(하우스·909) 포함 0.916.
>
> **권장 툴 설정:** 데모 드럼 = 하우스/EDM, 킥 음색 = 909, 드럼 볼륨 70%, 펌핑 기준 = 4분 정박(데모 드럼을 꺼도 펌핑이 남는다), 전체 스윙 0%(파일에 들어 있음), 바이닐 노이즈 끔. 템포·격자·키·딜레이(점8분)는 파일을 불러오면 적용된다.

## 읽는 법

- **시간 기준:** 124BPM(4분음표 기준, JSON `bpm`, 없으면 130). 1박 = 4분음표 = 0.4839초, 격자 16분(JSON `grid`, 없으면 8): 칸 하나 = 0.25박 = 16분음표 = 0.121초, 16박 = 4마디 = 64칸, 루프 = 7.7419초. 루프는 이음매 없이 반복한다. 표의 초는 반올림한 값이고 정확한 칸 시간은 15 / 124초다.
- **칸 번호:** 0~63. 칸 i는 루프 시작 후 i x 0.121초에 울린다. "박.위치" 표기로 칸 0 = 1.0, 칸 1 = 1.25, 칸 2 = 1.5, 칸 3 = 1.75, 칸 4 = 2.0 … 칸 63 = 16.75다.
- **음 표기:** 과학적 음이름(C4 = MIDI 60, 샵 표기). 쉬는 칸은 `-`, 음높이 없는 타악은 `X`, 같은 칸의 여러 음(화음)은 `+`로 잇는다.
- **세기:** 음 뒤 `@m`은 중(0.7), `@w`는 약(0.4)이고 표기가 없으면 강(1.0)이다 (타악은 `X@m`). JSON `velocity`는 노트 게인 배율이고 없으면 1이다.
- **노트 길이:** 기본 1칸이다. `C3*4`처럼 `*칸 수`가 붙은 음높이 노트는 그만큼 이어지고 표에서 이어지는 칸은 `=`다(JSON `length`, 없으면 1, 타악은 쓰지 않음). 게이트 = max(길이 x 0.121초, 어택+디케이, 홀드)이고 루프 끝을 넘는 길이는 루프 끝에서 자른다. 악기의 릴리스는 게이트 뒤로 이어진다.
- **롤:** `X/3`처럼 `/N`이 붙은 노트는 그 칸에서 N번 나눠 친다 (JSON `repeat` 2~4, 없으면 1). 칸(스윙 반영)을 N등분한 간격으로 같은 세기로 치고, 한 번의 게이트는 그 간격이다. 롤 노트는 길이를 쓰지 않는다(1칸). 표기 순서는 음, 길이, 롤, 세기다 (예: `C3/2@m`).
- **스윙:** 없음. JSON에 `groove.swing`이 있으면 칸 i의 시각 = i x 0.121초 + (i가 홀수면 swing x 0.121초)다.
- **믹스 설정 (유물별, 없으면 0):** `sidechain`은 킥마다 유물 소리를 (1 - 값)까지 0.01초에 눌렀다가 0.2초에 되돌린다. 4분 정박 킥(매 박 머리) 기준으로 설계했다. `reverbSend`·`delaySend`는 공통 리버브(감쇠 노이즈 임펄스 1.6초)와 공통 딜레이(점8분 = 0.75박 = 0.3629초, JSON `delayNote`, 없으면 3/8, 피드백 0.35, 피드백 로우패스 3000Hz)로 보내는 양이다. `lofi`는 계단 곡선(12비트에서 3비트로)과 로우패스(18000Hz에서 2500Hz로)를 값에 따라 건다. `lowCut`(저음 깎기)은 하이패스 20 x (800 / 20)^값 Hz, `highCut`(고음 깎기)은 로우패스 20000 x (800 / 20000)^값 Hz다 (값 1이면 둘 다 800Hz, Q 0.707, 12dB/oct). 소리 경로는 볼륨, 사이드체인, 하이패스, 로우패스, 로파이 순이고 센드는 그 뒤에서 뽑는다.
- **데모 드럼:** 툴의 데모 드럼(킥·스네어)은 미리듣기 전용이며 이 데이터에 없다.
- **스케일:** A 도리안 (C 도리안 + root 9) (반음 간격 0 2 3 5 7 9 10). 음높이는 C 기준 스케일 음에 키 `root`(9) 반음을 더한다(JSON `root` 0~11, 없으면 0). 음높이 악기는 스케일 음 8행(JSON `pitchRows` 8 또는 15, 없으면 8, 행 0이 가장 낮다), 타악은 행 1개다. 노트의 `midi`·`pitch`는 키와 유물의 옥타브 이동을 반영한 실제 음이다.
- **유물 설정 (유물별, 없으면 기본):** `swing`(0~0.5)이 있으면 그 유물만 이 스윙을 쓰고 없으면 전체 스윙을 따른다. `octaveShift`(-2~+2)는 음을 옥타브 단위로 옮긴다(MIDI 0~127을 넘으면 옥타브 단위로 안으로 접는다). `pan`(-1 왼쪽 ~ 1 오른쪽)은 마스터로 가는 소리만 좌우로 보내고 리버브·딜레이 센드는 가운데에서 뽑는다. `filterSweep`({ from, to }, 각 0~1)은 루프 머리에서 끝까지 로우패스를 20000 x (800 / 20000)^from Hz에서 ^to Hz로 지수 램프로 움직이고 루프마다 처음으로 돌아간다(고음 깎기와 따로 직렬로 건다).
- **원본 데이터:** 맨 아래 JSON이 원본이고 위의 표는 JSON에서 만든 것이다. 둘이 다르면 JSON을 따른다. 툴의 불러오기도 JSON만 읽는다.
- **게임 반영 시 주의:** 게임의 쿵(A)·짝(S) 판정 소리와 겹치지 않게 킥·스네어 음색은 쓰지 않았다. 템포와 격자는 위 시간 기준을 따르며 게임 링 박자(0.3초)와 묶여 있지 않다. 볼륨(`volume` x `mixVolume`)은 상대값이다. 합성 파라미터는 Web Audio API 기준(오실레이터 파형, BiquadFilter, 게인 엔벨로프)이다.
- **선택 파라미터:** `distortion`(WaveShaper tanh 곡선, drive가 클수록 강함, 필터 앞), `fm`(사인 모듈레이터가 주파수를 변조, 깊이 = index x 모듈레이터 Hz가 decay초 동안 0으로), `vibrato`(LFO로 detune을 ±depth센트 흔듦, delay초 뒤 시작), `hold`(게이트를 max(1칸, 어택+디케이, hold)로 늘림), `filterLfo`(사인 LFO가 메인 필터 주파수에 ±depth Hz를 rate Hz로 더함, 노트 시작에 위상 0), `spread`(오실레이터를 좌우로 -spread ~ +spread에 고르게 벌림), `formants`(메인 필터 대신 병렬 밴드패스 [{ freq, Q, gain }]를 지나 합침, 보컬 모음)는 있는 프리셋에만 쓴다. 없으면 그 처리를 하지 않는다.
