# 유물 비트 설계서

4Bit_Prototype 유물 비트 메이커(`relic-beat-tool/`)에서 내보낸 파일이다. 유물마다 악기 하나로 찍은 16박(4마디) 루프다.

> **장르 설계: 딥하우스 v1 — 16마디 사이클로 숨 쉬는 4마디 루프.** 120BPM, 16분 격자 64칸, F 단조(C 자연 단음계 + root 5), 15행, 사이클 4루프(16마디), 딜레이 점8분. 킥은 데모 드럼(하우스/EDM, 딥 킥)이 매 박에 치고, 베이스·건반은 킥 칸(0·4·8·12)을 비운다.
>
> **화성:** Fm9(마디 1·2) → B♭m9(마디 3·4). 화성이 2마디마다 바뀌어 하우스 v1보다 느리고 깊다. 로즈 보이싱은 Fm9 = A♭3-E♭4-G4-C5, B♭m9 = A♭3-D♭4-F4-C5로 A♭과 C를 붙잡고 E♭→D♭, G→F만 온음으로 움직인다. 두 코드의 공통음 F·A♭·C는 패드와 스트링이 루프 내내 붙잡는다. 충돌 검사는 단2도 계열(1·13·25반음)만 막았다. 9화음의 장7도 색(예: G4와 A♭3)은 일부러 남겼다.
>
> **새 기능 사용:**
> - **공간:** 로즈·패드·스트링에 코러스(30~40%), 보컬·패드·스트링·스냅·벨에 홀 리버브(25~50%).
> - **질감:** 로즈는 트레몰로 로즈(좌우 오토팬), 훅은 보컬 챱 "우", 응답은 "에", 패드는 보컬 패드. 베이스·로즈·보컬·오르간에 테이프(20~30%).
> - **16마디 흐름:** 보컬 패드와 오르간은 필터 스윕 `upDown`으로 16마디 동안 열렸다 닫힌다. 스트링은 3·4루프에만 나오고 위로 열린다. 탬버린은 2루프부터, 다운리프터는 1루프, 라이저는 4루프에만 나온다.
>
> **역할 (등급별, 유물 이름과 무관):**
> - 일반(뼈대): 서브우퍼 = 딥 베이스(한 옥타브 아래, 16분 당김), 에어 드럼 = 808 서브(같은 칸·같은 음), 리허설 = 로즈 트레몰로 9화음 엇박 컴핑, 레퍼토리 = 소울 보컬 훅 "우", 크래시 심벌 = 보컬 패드, 킥 솔로 = 오프비트 오픈 하이햇, 스네어 솔로 = 16분 셰이커(스윙 25%)
> - 희귀(색깔): 메트로놈 = 16분 하이햇, 스포르찬도 = 핑거 스냅(홀), 탭 댄스 = 콩가, 워킹 베이스 = 오르간 스탭, 카운터포인트 = 보컬 챱 "에" 응답, 프리스타일 = 탬버린(2루프부터), 턴테이블 = 벨(홀 + 딜레이)
> - 에픽(16마디 흐름): 크레센도 = 스트링(3·4루프), 퀀타이즈 = 라이저(4루프), 페르마타 = 다운리프터(1루프)
>
> **훅:** E♭4-C4(길게) / E♭4-F4-G4(위로) / F4-D♭4(길게) / F4-A♭4-F4. 마디 1·3은 내려가 쉬고 마디 2·4는 올라간다. "에" 챱은 훅이 쉬는 칸(11·12, 30·31, 43·44, 62·63)에서만 짧게 대답한다.
>
> **검증:** 17개를 모두 겹쳐 릴리스 꼬리와 딜레이 메아리까지 계산했을 때 단2도 계열 충돌 0건, 약한 겹침 0건. 게임식 추첨(카드 3장, 등급 60/30/10, 2만 회)에서 베이스 없음 31.2%, 중음 3개 이상 5.3%. 렌더 피크(유물 볼륨 반영)는 단독 0.798 이하, 무작위 5개 사이클 믹스 6개 0.918 이하, 데모 드럼(딥 킥) 포함 0.924. 사이클 WAV와 루프 WAV 모두 이음매 없음.
>
> **권장 툴 설정:** 데모 드럼 = 하우스/EDM, 킥 음색 = 딥, 드럼 볼륨 60~70%, 펌핑 기준 = 4분 정박, WAV 길이 = 한 사이클(16마디 흐름까지 들으려면), 바이닐 노이즈 켜기(취향). 템포·격자·키·행 수·사이클·딜레이는 파일을 불러오면 적용된다. 등장 루프와 필터 스윕은 믹스 재생을 16마디 이상 들어야 들린다.

## 읽는 법

- **시간 기준:** 120BPM(4분음표 기준, JSON `bpm`, 없으면 130). 1박 = 4분음표 = 0.5초, 격자 16분(JSON `grid`, 없으면 8): 칸 하나 = 0.25박 = 16분음표 = 0.125초, 16박 = 4마디 = 64칸, 루프 = 8초. 루프는 이음매 없이 반복한다. 표의 초는 반올림한 값이고 정확한 칸 시간은 15 / 120초다.
- **칸 번호:** 0~63. 칸 i는 루프 시작 후 i x 0.125초에 울린다. "박.위치" 표기로 칸 0 = 1.0, 칸 1 = 1.25, 칸 2 = 1.5, 칸 3 = 1.75, 칸 4 = 2.0 … 칸 63 = 16.75다.
- **음 표기:** 과학적 음이름(C4 = MIDI 60, 샵 표기). 쉬는 칸은 `-`, 음높이 없는 타악은 `X`, 같은 칸의 여러 음(화음)은 `+`로 잇는다.
- **세기:** 음 뒤 `@m`은 중(0.7), `@w`는 약(0.4)이고 표기가 없으면 강(1.0)이다 (타악은 `X@m`). JSON `velocity`는 노트 게인 배율이고 없으면 1이다.
- **노트 길이:** 기본 1칸이다. `C3*4`처럼 `*칸 수`가 붙은 음높이 노트는 그만큼 이어지고 표에서 이어지는 칸은 `=`다(JSON `length`, 없으면 1, 타악은 쓰지 않음). 게이트 = max(길이 x 0.125초, 어택+디케이, 홀드)이고 루프 끝을 넘는 길이는 루프 끝에서 자른다. 악기의 릴리스는 게이트 뒤로 이어진다.
- **롤:** `X/3`처럼 `/N`이 붙은 노트는 그 칸에서 N번 나눠 친다 (JSON `repeat` 2~4, 없으면 1). 칸(스윙 반영)을 N등분한 간격으로 같은 세기로 치고, 한 번의 게이트는 그 간격이다. 롤 노트는 길이를 쓰지 않는다(1칸). 표기 순서는 음, 길이, 롤, 세기다 (예: `C3/2@m`).
- **스윙:** 없음. JSON에 `groove.swing`이 있으면 칸 i의 시각 = i x 0.125초 + (i가 홀수면 swing x 0.125초)다.
- **믹스 설정 (유물별, 없으면 0):** `sidechain`은 킥마다 유물 소리를 (1 - 값)까지 0.01초에 눌렀다가 0.2초에 되돌린다. 4분 정박 킥(매 박 머리) 기준으로 설계했다. `reverbSend`·`delaySend`는 공통 리버브(감쇠 노이즈 임펄스 1.6초)와 공통 딜레이(점8분 = 0.75박 = 0.375초, JSON `delayNote`, 없으면 3/8, 피드백 0.35, 피드백 로우패스 3000Hz)로 보내는 양이다. `lofi`는 계단 곡선(12비트에서 3비트로)과 로우패스(18000Hz에서 2500Hz로)를 값에 따라 건다. `lowCut`(저음 깎기)은 하이패스 20 x (800 / 20)^값 Hz, `highCut`(고음 깎기)은 로우패스 20000 x (800 / 20000)^값 Hz다 (값 1이면 둘 다 800Hz, Q 0.707, 12dB/oct). `hallSend`는 두 번째 리버브 '홀'로 보내는 양이다: 짧은 룸(위 공통 리버브 1.6초)과 달리 길이 4초, 프리딜레이 30ms, 좌우 다른 노이즈, 꼬리 뒤쪽일수록 어둡고 리턴에 하이패스 250Hz·로우패스 6000Hz. `chorus`는 스테레오 코러스(좌우 지연 15ms를 ±3ms 반대 위상으로 흔듦, LFO는 1마디에 한 번 = bpm / 240 Hz, 젖은 소리 = 값, 마른 소리 = 1 - 값 x 0.5). `tape`는 아날로그 테이프 질감(포화 tanh drive 1 + 4 x 값, 흔들림 8ms 지연을 ±0.6 x 값 ms로 2박에 한 번, 고음 감쇠 로우패스 18000 x (6000 / 18000)^값 Hz)로, 디지털 비트 감소인 `lofi`와 다르다. 템포에 묶인 LFO는 모두 루프 머리에서 위상 0이다. 소리 경로는 볼륨, 사이드체인, 하이패스, 로우패스, 필터 스윕, 테이프, 로파이, 코러스, 팬 순이고 리버브·홀·딜레이 센드는 팬 앞(코러스 뒤)에서 뽑는다.
- **데모 드럼:** 툴의 데모 드럼(킥·스네어)은 미리듣기 전용이며 이 데이터에 없다.
- **스케일:** F 자연 단음계 (C 자연 단음계 + root 5) (반음 간격 0 2 3 5 7 8 10). 음높이는 C 기준 스케일 음에 키 `root`(5) 반음을 더한다(JSON `root` 0~11, 없으면 0). 음높이 악기는 스케일 음 15행(JSON `pitchRows` 8 또는 15, 없으면 8, 행 0이 가장 낮다), 타악은 행 1개다. 노트의 `midi`·`pitch`는 키와 유물의 옥타브 이동을 반영한 실제 음이다.
- **유물 설정 (유물별, 없으면 기본):** `swing`(0~0.5)이 있으면 그 유물만 이 스윙을 쓰고 없으면 전체 스윙을 따른다. `octaveShift`(-2~+2)는 음을 옥타브 단위로 옮긴다(MIDI 0~127을 넘으면 옥타브 단위로 안으로 접는다). `pan`(-1 왼쪽 ~ 1 오른쪽)은 마스터로 가는 소리만 좌우로 보내고 리버브·딜레이 센드는 가운데에서 뽑는다. `filterSweep`({ from, to, shape? }, 각 0~1)은 사이클 머리에서 끝까지 로우패스를 20000 x (800 / 20000)^값 Hz로 움직이고 사이클마다 처음으로 돌아간다(고음 깎기와 따로 직렬로 건다). `shape`는 up(from -> to, 없으면 이것), down(to -> from), upDown(사이클 앞 절반 from -> to, 뒤 절반 to -> from). `loops`(사이클 안 루프별 true/false)가 있으면 false인 루프에서 그 유물의 노트를 치지 않는다(없으면 모든 루프, 모자란 칸은 켜짐).
- **사이클:** 4루프 = 16마디 (JSON `cycleLoops` 1, 2, 4, 8, 없으면 1). 노트 데이터는 4마디 한 루프이고, 필터 스윕과 등장 루프 같은 자동화가 사이클 전체에 걸친다.
- **원본 데이터:** 맨 아래 JSON이 원본이고 위의 표는 JSON에서 만든 것이다. 둘이 다르면 JSON을 따른다. 툴의 불러오기도 JSON만 읽는다.
- **게임 반영 시 주의:** 게임의 쿵(A)·짝(S) 판정 소리와 겹치지 않게 킥·스네어 음색은 쓰지 않았다. 템포와 격자는 위 시간 기준을 따르며 게임 링 박자(0.3초)와 묶여 있지 않다. 볼륨(`volume` x `mixVolume`)은 상대값이다. 합성 파라미터는 Web Audio API 기준(오실레이터 파형, BiquadFilter, 게인 엔벨로프)이다.
- **선택 파라미터:** `distortion`(WaveShaper tanh 곡선, drive가 클수록 강함, 필터 앞), `fm`(사인 모듈레이터가 주파수를 변조, 깊이 = index x 모듈레이터 Hz가 decay초 동안 0으로), `vibrato`(LFO로 detune을 ±depth센트 흔듦, delay초 뒤 시작), `hold`(게이트를 max(1칸, 어택+디케이, hold)로 늘림), `filterLfo`(사인 LFO가 메인 필터 주파수에 ±depth Hz를 rate Hz로 더함, 노트 시작에 위상 0), `spread`(오실레이터를 좌우로 -spread ~ +spread에 고르게 벌림), `tremolo`(노트 게인을 beats박 주기로 1 - depth ~ 1 사이에서 흔듦, 루프 머리 기준 위상, stereo면 좌우 반대 위상), `formants`(메인 필터 대신 병렬 밴드패스 [{ freq, Q, gain }]를 지나 합침, 보컬 모음. 자체 필터가 없는 노이즈도 포먼트를 지난다)는 있는 프리셋에만 쓴다. 없으면 그 처리를 하지 않는다.
