# 하우스 v1 — 역할표

`relic-beats-house-v1.md`의 설계 근거 문서다. 노트 데이터의 원본은 그 설계서의 JSON이다.
(파일 이름이 `relic-beats-*`가 아니어서 툴 불러오기와 기준 렌더 대상에 들어가지 않는다.)

## 1. 방향

- 리듬게임에서 박을 놓치지 않게 하는 것이 목표다. 킥(매 박), 오픈 하이햇(8분 뒷박), 클랩·스냅(2·4박)이 박을 계속 알려 준다.
- 베이스와 화음은 킥 칸(0·4·8·12)을 비운다. 베이스는 킥과 비켜 치기(`mc-rhythm-section` §7.1의 전자음악 형태)라 킥이 묻히지 않는다.
- 루프 음악은 반복 자체가 추진력이다(`mc-style-edm` §5.2). 그래서 2코드 반복을 쓰고, 훅만 마디 4에서 끝을 바꾼다.
- 스윙은 하이햇·셰이커·클라베·콩가에만 20%를 건다. 베이스와 화음은 곧게 둔다(유물별 스윙).

## 2. 설정과 화성

- 124BPM, 16분 격자(64칸 = 4마디), 키 A(C 도리안 + root 9 = A 도리안), 행 8개(A B C D E F# G A), 딜레이 점8분(3칸), 전체 스윙 0.
- Am7(칸 0~15) → D9(16~31) → Am7(32~47) → D9(48~63).
- 공통음 A·C·E. 부딪히는 음은 G(Am7) ↔ F#(D9) 하나다. 마디 경계를 넘어 울리는 음은 공통음만 쓴다.
- 보이싱: Am7 = C-E-G, D9 = C-E-F#-A, 마디 끝 연결 = C-E-A.

## 4. 검증 결과

| 항목 | 값 |
|---|---|
| 강한 반음 충돌 (17개 전부 + 릴리스 꼬리 + 딜레이 메아리) | 0건 |
| 약한 겹침 | 4건, 모두 플럭 F#5 메아리가 다음 마디 G와 0.17칸 겹침 |
| 코드 구성음 비율 | 97.7% |
| 게임식 추첨 2만 회: 베이스 없음 / 베이스 2개 / 중음 3개 이상 | 31.3% / 17.5% / 0.8% |
| 렌더 피크 (유물 볼륨 반영): 단독 / 무작위 5개 믹스 12개 / 17개 전부 / 데모 드럼 포함 | 0.727 / 0.903 / 0.900 / 0.916, NaN 없음 |
| 불러오기 | `parseDesign`으로 다시 읽어 17개 유물·노트 351개·믹스·유물 설정·전역 설정(124BPM, 16분, root 9, 점8분)이 같음 |

- 처음 계산에서 마지막 마디 베이스 G 픽업이 D9 꼬리의 F#과 겹쳐 E로 바꿨다. 첫 렌더에서 보컬 챱과 플럭이 피아노보다 작아 볼륨을 올렸다.
- 참고: `renderLoop`는 레이어로 넘긴 `volume`만 쓰고 유물 볼륨을 따로 곱하지 않는다. 이전 설계서들(신스펑크 v1, 붐뱁 v2, 신스웨이브 v2)의 피크 수치는 볼륨 1로 잰 값이다.
