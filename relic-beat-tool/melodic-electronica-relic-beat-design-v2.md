# 유물 비트 설계서

4Bit_Prototype 유물 비트 메이커(`relic-beat-tool/`)용 유물 악기 모드 설계서다. 5종 악기로 구성한 16박(4마디) 멜로딕 일렉트로니카 루프다.

> **장르 설계: 멜로딕 일렉트로니카 v1 — 밝고 유려한 4마디 루프.** 128BPM, 16분 격자 64칸, A 자연 단음계(C 자연 단음계 + root 9), 15행, 사이클 1루프(4마디), 딜레이 점8분(3/16). 별도 킥 프리셋은 두지 않고 딥 베이스의 4분 정박 펄스가 저음의 추진력을 맡는다. 클랩은 2·4박, 하이햇은 16분 연속으로 리듬을 채운다.
>
> **화성:** Am → F → C → G. 마디마다 코드가 바뀌는 4마디 진행이다. 플럭은 각 코드의 구성음을 8분음표 아르페지오로 펼치고, 패드는 코드톤을 한 마디 동안 유지한다. F 코드에서 F4를 A3·C4보다 위에 두어 저음역을 과도하게 내리지 않고, G 코드에서는 B3·D4·G4로 자연스럽게 연결한다.
>
> **공간과 질감:** 플럭에는 짧은 리버브·점8분 딜레이·약한 코러스를 주어 멜로디의 잔향을 만든다. 패드는 코러스와 4초 홀 리버브로 넓히고, 사이클 전체에 `upDown` 필터 스윕을 적용한다. 하이햇은 중앙보다 약간 오른쪽, 플럭은 약간 왼쪽에 배치해 패드와 베이스의 중앙 공간을 남긴다.
>
> **역할:** 딥 베이스 = 정박 저음 펄스와 간헐적 엇박, 핸드 클랩 = 2·4박 백비트, 클로즈드 하이햇 = 16분 추진력, 신스 플럭 = 메인 아르페지오, 슈퍼소 패드 = 코드와 공간감.
>
> **킥 정책:** 이 설계의 5종 악기 제한 때문에 유물 프리셋으로 킥을 추가하지 않았다. 데모 드럼을 켜면 별도의 킥이 더해지므로, 기본 청취에서는 데모 드럼을 끄는 것을 권장한다. 사이드체인을 듣고 싶다면 펌핑 기준을 `4분 정박`으로 둔다.
>
> **검증 범위:** 아래 노트 수·음역·박자표·한 줄 패턴·JSON은 같은 노트 배열에서 생성한 값이다. 프리셋 내부의 오실레이터·필터·엔벨로프 수치는 제공된 지침서에 개별 정의가 없어 임의로 만들지 않고 툴 내장 프리셋 정의를 사용하도록 했다. 오디오 렌더 피크와 실제 청감은 툴에서 재생해 확인해야 한다.
>
> **권장 툴 설정:** 모드 = 유물 악기, BPM = 128, 격자 = 16분, 키 = A, 스케일 = 자연 단음계, 행 수 = 15, 사이클 = 1루프, 딜레이 = 점8분(3/16), 스윙 = 0%, 데모 드럼 = 없음, 펌핑 기준 = 4분 정박. WAV는 한 루프면 충분하다.

## 읽는 법

- **시간 기준:** 128BPM(4분음표 기준, JSON `bpm`). 1박 = 60 / 128초 = 0.46875초. 16분 격자(JSON `grid: 16`)에서 한 칸 = 15 / 128초 = 0.1171875초. 16박 = 4마디 = 64칸, 루프 길이 = 7.5초다. 루프는 반복 재생한다.
- **칸 번호:** 0~63. 칸 i는 루프 시작 후 i × 0.1171875초에 울린다. 박.위치 표기로 칸 0 = 1.0, 칸 1 = 1.25, 칸 2 = 1.5, 칸 3 = 1.75, 칸 63 = 16.75다.
- **음 표기:** 과학적 음이름(C4 = MIDI 60, 샵 표기). 쉬는 칸은 `-`, 음높이 없는 타악은 `X`, 같은 칸의 여러 음(화음)은 `+`로 잇는다.
- **세기:** 음 뒤 `@m`은 중(0.7), `@w`는 약(0.4)이고 표기가 없으면 강(1.0)이다. 타악은 `X@m`처럼 표기한다. JSON `velocity`는 노트 게인 배율이며 생략하면 1이다.
- **노트 길이:** 기본 1칸이다. `A3*16`처럼 `*칸 수`가 붙은 음높이 노트는 그만큼 이어지고, 이어지는 칸은 `=`로 표시한다(JSON `length`). 타악은 `length`를 쓰지 않는다. 게이트는 max(노트 길이 × 한 칸 시간, 어택+디케이, 홀드)이며 릴리스는 게이트 뒤에 이어진다.
- **롤:** `X/3`처럼 `/N`이 붙으면 한 칸을 N등분해 N번 친다(JSON `repeat`, 2~4). 이번 설계에는 롤을 사용하지 않았다.
- **스윙:** 없음. `groove.swing: 0`이므로 모든 칸은 정시각에 재생된다. 유물별 `swing`이 있으면 전체 스윙 대신 해당 유물의 값을 사용한다.
- **믹스 설정:** `sidechain`은 펌핑 기준 칸마다 소리를 (1 - 값)까지 0.01초에 눌렀다가 0.2초에 되돌린다. `reverbSend`는 공통 1.6초 리버브, `delaySend`는 공통 딜레이로 보내는 양이다. `delayNote: 3/16`은 점8분음표(0.75박)이며 128BPM에서 약 0.3516초다. 딜레이 피드백은 0.35, 피드백 로우패스는 3000Hz다. `chorus`는 좌우 지연 15ms를 ±3ms로 흔드는 스테레오 코러스다. `hallSend`는 4초 홀 리버브(프리딜레이 30ms, 리턴 하이패스 250Hz·로우패스 6000Hz)로 보내는 양이다. `tape`는 포화·속도 흔들림·고음 감쇠를 더하는 아날로그 테이프 질감이며 `lofi`의 디지털 비트 감소와 다르다.
- **필터·컷:** `lowCut`은 하이패스 20~800Hz, `highCut`은 로우패스 20kHz~800Hz를 지수 곡선으로 움직인다. 이번 설계에서는 별도 lowCut/highCut/lofi/tape를 사용하지 않았다. `filterSweep`은 사이클 동안 로우패스 컷오프를 움직인다. 0은 20kHz, 1은 800Hz다.
- **스케일:** A 자연 단음계 = C 자연 단음계 + root 9. JSON `scale`은 C 기준 이름과 간격 `[0,2,3,5,7,8,10]`을 기록하고, 최상위 `root: 9`가 모든 음을 A 기준으로 올린다. 음높이 악기는 15행이며 행 0이 가장 낮다. 타악은 행 1개(row 0)다. 프리셋 옥타브와 root를 적용한 실제 음을 JSON `midi`·`pitch`에 기록했다.
- **유물 설정:** `pan`은 -1 왼쪽~+1 오른쪽이다. `octaveShift`는 음을 옥타브 단위로 옮긴다. `filterSweep`의 `shape: upDown`은 사이클 앞 절반에서 `from`→`to`, 뒤 절반에서 `to`→`from`으로 움직인다. `loops`는 사이클 안에서 유물이 등장할 루프를 지정하지만 이번 설계는 1루프라 생략했다.
- **데모 드럼:** 데모 드럼의 킥·스네어는 유물 JSON에 포함되지 않는 별도 미리듣기 설정이다. 이 설계는 베이스가 저음 박자를 맡으므로 기본적으로 데모 드럼을 끈다.
- **JSON 원본:** 맨 아래 JSON 코드블록이 불러오기 데이터의 원본이다. 표·설명과 JSON이 다르면 JSON을 따른다. 불러오기는 JSON만 읽는다.
- **프리셋 파라미터:** 제공된 `CLAUDE.md`에는 프리셋 ID·악기 유형·기본 옥타브는 있으나, 이번에 사용한 다섯 프리셋의 개별 `oscs`, `filter`, `env`, `gain` 값은 수록되어 있지 않다. 따라서 해당 값을 추정해 기재하지 않고 툴의 내장 프리셋을 그대로 사용한다.

## 딥 베이스

- **악기:** 딥 베이스 (`deep_bass`, 음높이 악기, 행 0 옥타브 2)
- **볼륨:** 95%
- **노트 수:** 24
- **믹스 설정:** 사이드체인 72%, 나머지 믹스 센드 0%

합성 파라미터:

- 툴 내장 프리셋의 합성 설정을 그대로 사용한다. 개별 오실레이터·필터·엔벨로프 수치는 제공된 기준 문서에 없어 별도 수치로 재작성하지 않았다.

## 툴에서 재생할 때의 설정

1. 모드를 **유물 악기**로 설정한다.
2. 키를 **A**, 스케일을 **자연 단음계**, 행 수를 **15행**으로 설정한다.
3. 격자를 **16분음표**, 템포를 **128 BPM**, 사이클을 **1루프**로 설정한다.
4. 딜레이를 **점8분(3/16)**, 스윙을 **0%**로 설정한다.
5. 데모 드럼은 **없음**으로 둔다. 사이드체인을 사용할 때 펌핑 기준은 **4분 정박**으로 설정한다.
6. 다섯 유물을 믹스 바에 넣고, 각 유물 볼륨을 JSON의 `volume` 값에 맞춘다.
7. 먼저 베이스·클랩·하이햇을 재생한 뒤 플럭과 패드를 추가해 저음·중음·고음의 균형을 확인한다.

**최종 의도:** 베이스가 4분 정박으로 곡을 앞으로 밀고, 클랩이 백비트를 고정한다. 하이햇은 16분의 속도감을 만들며, 플럭이 기억에 남는 멜로디를 담당한다. 패드는 Am–F–C–G의 화성을 넓게 받쳐 밝고 감성적인 여름 드라이브 분위기를 완성한다.
